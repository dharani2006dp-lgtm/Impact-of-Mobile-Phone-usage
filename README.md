# Impact of Mobile Phone Usage on Students' Academic Performance

## 1. Project Overview
This project studies the impact of mobile phone usage on students' academic performance.

The study analyzes students' mobile phone usage habits and their relationship with academic performance and concentration.

## 2. Project Objectives
- To understand students' mobile phone usage habits.
- To study the relationship between mobile usage and academic performance.
- To understand the impact of mobile phones on students' concentration.
- To analyze survey responses.

## 3. Dataset Information
- Total Respondents: 500+
- Data Collection Method: Survey
- Study Area: Students' mobile phone usage and academic performance.

## 4. Key Findings
- 39.7% of respondents belong to the 70–80% academic performance group.
- 8.9% belong to the below 60% group.
- 55.6% agree or strongly agree that mobile phone usage affects concentration.

## 6. Conclusion
This study explores how mobile phone usage may influence students' concentration and academic performance.
